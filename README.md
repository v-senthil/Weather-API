# Weather API

A one-file script that prompts for a city name and prints the current weather from OpenWeatherMap.

## Use
1. Get an API key from [OpenWeatherMap](https://openweathermap.org/api) and put it in `wether.py` in place of `YOUR_API_KEY`.
2. `pip install requests`
3. `python wether.py`, type a city name, and read the JSON response.

College project, 2019–2021.
